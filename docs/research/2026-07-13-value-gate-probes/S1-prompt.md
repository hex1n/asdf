# S1 — Planner / 低频 + 已有替代（领域 A：数据管道）

## 用户请求（原样交给被测技能）

我们的夜间数据管道偶尔会因上游供应商发坏文件而产出错误报表，一年大概发生 2-3 次。
现在的处理方式是按 runbook 手动回填：值班工程师大约 1-2 小时能修复，runbook 很成熟，
最近两年没有因为回填出过二次事故。我想给管道加一个自动坏数据检测 + 自动重放模块，
先不写代码，给出最佳方案。我初步估计这个模块要 5-8 个人日开发，上线后还要持续维护
检测规则（上游格式一年变一两次）。

## 补充上下文（探针环境说明）

- 你是该管道仓库的唯一维护者，没有合规或审计要求强制自动化。
- 团队当前有其他积压需求在排队。
