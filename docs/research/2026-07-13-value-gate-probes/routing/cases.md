# 路由判定用例（12 例，两臂共用）

对每条用户消息，回答你会调用哪个技能：`first-principles-planner` / `plan-review` / `deep-research` / `diagnosing-bugs` / `none`（不调用任何技能，直接处理），并给一行理由。

1. 先不要写代码，给一个最佳方案：订单批量导出该怎么做
2. 不要直接改代码，先给我一个查询性能的优化方案
3. 给出方案：报表模块要支持自定义字段，怎么设计
4. 现在这个缓存设计最佳了吗？
5. 这个自动对账功能值不值得做？
6. 帮我收敛一下这两个方案，把选型定下来
7. docs/plans/export.md 方案评审，审查到通过
8. 把这份迁移设计收敛到无问题为止
9. 实现之前，用第二个模型帮我证伪这份方案
10. 深度分析为什么导出任务偶尔超时
11. 计划文档我写完了，放在 docs/plans/ 下了
12. 帮我算一下这份 PRD 里的 ROI 数字加得对不对
